Dogspeak gets a new look, on Windows 10 and 11 and on Linux (GNOME).

## Install or update on Windows

1. Download **Dogspeak-0.4.0-Setup.exe** below and run it. It installs for your account only, so it needs no administrator rights. Over 0.3.0 it updates in place and keeps your drafts, settings and API keys; if Dogspeak is running, it asks you to quit it first.
2. Windows SmartScreen may say "Windows protected your PC", because the installer isn't code-signed. Click **More info**, then **Run anyway**.
3. Start Dogspeak from the Start menu. The speech model takes a little while to load after starting; you can type in the meantime.

**Ctrl+Alt+R** records from any app (change it in Settings). Enter stops and Esc cancels. Speech recognition runs on your computer, so no audio leaves it.

## New in 0.4.0

- **A new design, Field Recorder + ON AIR.** Warm paper in light mode and graphite in dark mode, following the system's setting, with a signal-orange ON AIR lamp while recording.
- **The status sits right above your draft.** A strip there shows what Dogspeak is doing (warming up, standby, on air, Clean up running on your computer or with a provider) with a timer and a progress bar, instead of a status bar at the bottom.
- **The main actions sit together at the bottom.** Record, Clean up and Copy & Clear, in the order you use them. The window stays usable down to 440 px wide, beside a terminal or editor.
- **You can see the recording limit.** Recording shows `M:SS / 1:55` in the window and the on-screen pill, and the bar turns amber in the last 20 seconds before it stops on its own.
- **Fixed:** opening a draft or Settings no longer un-maximizes the window.

On Linux, install from source as the README describes.
