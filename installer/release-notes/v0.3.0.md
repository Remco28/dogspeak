Dogspeak now runs on **Windows 10 and 11**, as well as on Linux (GNOME).

## Install on Windows

1. Download **Dogspeak-0.3.0-Setup.exe** below and run it. It installs for your account only, so it needs no administrator rights.
2. Windows SmartScreen may say "Windows protected your PC", because the installer isn't code-signed. Click **More info**, then **Run anyway**.
3. Start Dogspeak from the Start menu. The first start takes about 20 seconds while the speech model loads; you can type in the meantime.

**Ctrl+Alt+R** records from any app (change it in Settings). Enter stops and Esc cancels. Closing the window keeps Dogspeak in the tray; quit with Ctrl+Q or from the tray. Speech recognition runs on your computer, so no audio leaves it. The download is about 300 MB because it includes the speech model and its own Python.

To remove it: *Settings → Apps → Installed apps → Dogspeak → Uninstall*. It asks whether to delete your drafts and saved API keys too; the answer is No unless you choose Yes.

## New in 0.3.0

- **Windows version**: the same drafts, dictation at the cursor, Clean up, suggestions and versions as on Linux, plus a tray icon and the on-screen pill.
- **Copy & Clear** (Ctrl+Shift+X): copies the whole draft, checks the clipboard, then clears the text. Undo brings it back.
- Clean up with your own key for Claude (Anthropic), OpenRouter, OpenAI, Gemini, Groq, DeepSeek or a local Ollama model. On Windows, keys are kept in Windows Credential Manager.

On Linux, install from source as the README describes.
